# Project plan — Gwaneza Katia Nkurunziza

## One-paragraph description

Replicate and extend Hodler's (2018) synthetic-control estimate of Rwanda's post-genocide GDP recovery to human capital. The project reconstructs the published GDP result from Penn World Table 8.0, independently re-estimates synthetic-control weights, reproduces placebo-based inference, and extends the analysis to a human-capital outcome to assess whether Rwanda's human capital recovered alongside GDP.
