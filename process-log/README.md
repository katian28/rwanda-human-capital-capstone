# Process log

Create one dated entry per week. This log is evidence for project navigation and process documentation, not merely a task list.

Record:

- What was planned and what was completed
- Links to artifacts produced
- Decisions and their justification
- Problems, uncertainty, and failed approaches
- Feedback received and how it was evaluated
- Generative-AI use and how outputs were verified
- Priorities for the following week

Do not include private advisor notes or sensitive personal information in this public repository.
