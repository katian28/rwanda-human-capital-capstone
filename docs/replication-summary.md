# GDP replication: bottom line

**The path reconstructs closely. Formal inference improved once Hodler's real predictor set was assembled, but still falls short of conventional significance at the correct donor-pool size.** All three things are true at once.

## The path replicates, almost exactly

Independently re-estimated using Hodler's own documented predictor set (PWT 7.1 investment and openness, WDI inflation, Polity political regime, Freedom House political rights, UCDP conflict — not just lagged GDP, which this project used as a simplification before those five sources were assembled; see `code/14_predictor_assembly_check.R`), Rwanda's 1994 GDP gap comes out to **-0.588**, next to the published **-0.58** — the closest this project has gotten. Pre-treatment fit is tighter than before too: RMSPE **0.0495** versus published **0.0584**. The "GDP fell by roughly half in 1994 and took about seventeen years to recover" story holds up, now on Hodler's actual specification rather than an approximation of it.

Donor weights concentrate on Cameroon (0.548), Niger (0.298), Sudan (0.121), and a small Senegal weight (0.033) — different from the published distribution (spread across all nine donors) and from this project's earlier simplified-predictor estimate (which concentrated on Cameroon and Senegal). A similar aggregate path emerging from different weight vectors is a known feature of the method (multiple near-equally-good solutions), not evidence either estimation is wrong. Liberia is excluded from this donor pool entirely: it has zero WDI inflation data before 2002 (its own 1989-2003 civil wars), and its published weight was Hodler's smallest (0.032), so this is a small, documented exclusion.

## The significance improved, but still doesn't clear a conventional threshold

At the predictor-complete donor pool (29 Sub-Saharan African countries with real data for every one of Hodler's predictors, down from 39 when only GDP completeness was required — see `code/14_predictor_assembly_check.R` for why), **Rwanda's gap ranks 20th of 30 (p = 0.667)**. This is a real improvement over the earlier, predictor-simplified estimate (31st of 40, p = 0.775), but still not conventionally significant. Equatorial Guinea remains the dominant outlier in every version of this test (post-1994 oil boom, pre-treatment RMSPE 0.078 but post-treatment RMSPE 39.7) — a real, economically explicable deviation unrelated to Rwanda's genocide.

A smaller 9-country pool (the only countries with non-zero published weights, Liberia excluded as above) gives rank 3 of 9 (p = 0.333) — still not strong, but more favorable than the honest full-pool test, for the same reason as before: fewer, more similar comparison countries make any single deviation look more unusual by construction. **This project reports the full-pool result as the headline, not the smaller pool's more favorable number.** Applying Hodler's own documented placebo-exclusion rule to the full-pool test doesn't meaningfully change it either (rank 20 of 29, p = 0.690 — the rule drops only Nigeria, and does not touch the real driver of the ranking, large post-treatment volatility in countries like Equatorial Guinea that fit their own pre-treatment path just fine). See `results/placebo-restricted.md`, `results/placebo-hodler-rule.md`.

## Why the predictor-set rebuild mattered

This project initially used a simplified specification (three lagged-GDP special predictors) because Hodler's actual five external predictor sources hadn't been assembled. Sourcing and verifying all five surfaced two genuine data-mapping bugs along the way — Polity's country code is not ISO3 for most countries (Cameroon is "CAO", not "CMR"; similarly for several others), and Freedom House's pre-1990 survey editions needed a specific parsing rule (the edition label's second year, not its messy "Year(s) Under Review" field) to avoid silently losing 1989 entirely. Both were found and fixed by checking the actual downloaded files directly, not by assuming the sourcing agents' initial country-code guesses were correct. Liberia was the one donor with a genuine, unfixable gap (no inflation data at all before 2002), and was excluded rather than worked around.

## Why the earlier number moved too, and in which direction

Separately, mid-project, a real numerical bug was found and fixed in how this project's code was using the `Synth` package's `genoud` optimizer (`kernlab::ipop`, the package's inner solver, could silently return a suboptimal result near sparse donor-weight solutions). Fixing it — verified against `Synth`'s actual documented algorithm (Abadie, Diamond & Hainmueller 2011, *JSS* 42(13)), not just patched ad hoc — moved the full-pool placebo result from an early p = 0.53 to a more rigorous p = 0.775 using the simplified predictor set, and now to p = 0.667 using Hodler's real predictor set. The direction of each fix has been to make the pipeline more faithful to the documented method, not to chase a more favorable number — and the numbers have moved in both directions as a result (weaker after the optimizer fix, stronger after the full predictor set), which is itself evidence this is a genuine convergence toward the correct specification, not a search for a convenient one.

## One-line version

The path reconstructs almost exactly once Hodler's real predictor set is used; the statistical-significance claim improves but still does not clear a conventional threshold at the correct, predictor-complete donor pool; both are reported, with the properly-sized full-pool test treated as the headline rather than a smaller, more flattering one.
