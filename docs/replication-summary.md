# GDP replication: bottom line

**The path reconstructs almost exactly. Formal inference improved substantially once Hodler's full donor pool and real predictor set were assembled, but still falls short of conventional significance.** All three things are true at once.

## The path replicates, almost exactly

Independently re-estimated using Hodler's own documented predictor set (PWT 7.1 investment and openness, WDI GDP-deflator inflation, Polity political regime, Freedom House political rights, UCDP conflict — not just lagged GDP, which this project used as a simplification before those five sources were assembled; see `code/14_predictor_assembly_check.R`), Rwanda's 1994 GDP gap comes out to **-0.578**, next to the published **-0.58** — the closest this project has gotten, and closure by 2011 is likewise close (gap 0.028). Pre-treatment fit is also tighter than published: RMSPE **0.0421** versus published **0.0584**. The "GDP fell by roughly half in 1994 and took about seventeen years to recover" story holds up, now on Hodler's actual specification and his actual nine donors.

Donor weights spread across seven of the nine donors — Cameroon 0.460, Gabon 0.062, Liberia 0.026, Lesotho 0.034, Niger 0.102, Sudan 0.135, Senegal 0.183 (Congo and Mali at zero) — a distribution much closer in spread to the published one (also spread across all nine) than this project's earlier estimates managed. Liberia is included with all eight other donors: an earlier version of this pipeline used WDI CPI inflation, which has zero coverage for Liberia before 2002 (its own 1989-2003 civil wars) and would have forced dropping one of Hodler's own nine donors. Switching to WDI's GDP-deflator inflation series, which has full coverage for Liberia and the wider donor pool generally, fixed this without needing to drop anyone — a replication should imitate the original as closely as the data allows, not quietly narrow the donor pool because of an avoidable choice of inflation series.

## The significance improved substantially, but still doesn't clear a conventional threshold

At the predictor-complete donor pool (37 Sub-Saharan African countries with real data for every one of Hodler's predictors and for GDP itself — down from 39 when only GDP-only completeness was checked; Somalia is excluded separately because PWT 8.0 has no GDP data for it at all, a genuine gap unrelated to the inflation-series fix — see `code/14_predictor_assembly_check.R`), **Rwanda's gap ranks 18th of 38 (p = 0.474)**. This is a large improvement over the earlier CPI-based, Liberia-excluded estimate (20th of 30, p = 0.667), driven mainly by using the full, correctly-sourced donor pool rather than a shrunken one. Equatorial Guinea remains the dominant outlier in every version of this test (post-1994 oil boom, pre-treatment RMSPE 0.076 but post-treatment RMSPE 39.6) — a real, economically explicable deviation unrelated to Rwanda's genocide.

A smaller 9-country pool (Hodler's own published donors, all nine now included) gives rank 3 of 10 (p = 0.300) — still not strong, but more favorable than the honest full-pool test, for the same reason as before: fewer, more similar comparison countries make any single deviation look more unusual by construction. **This project reports the full-pool result as the headline, not the smaller pool's more favorable number.** Applying Hodler's own documented placebo-exclusion rule to the full-pool test doesn't meaningfully change it either (rank 18 of 35, p = 0.514 — the rule drops Nigeria, Liberia, and Zambia for poor pre-treatment fit, but does not touch the real driver of the ranking, large post-treatment volatility in countries like Equatorial Guinea that fit their own pre-treatment path just fine). See `results/placebo-restricted.md`, `results/placebo-hodler-rule.md`.

## Why the predictor-set rebuild mattered

This project initially used a simplified specification (three lagged-GDP special predictors) because Hodler's actual five external predictor sources hadn't been assembled. Sourcing and verifying all five surfaced two genuine data-mapping bugs along the way — Polity's country code is not ISO3 for most countries (Cameroon is "CAO", not "CMR"; similarly for several others), and Freedom House's pre-1990 survey editions needed a specific parsing rule (the edition label's second year, not its messy "Year(s) Under Review" field) to avoid silently losing 1989 entirely. Both were found and fixed by checking the actual downloaded files directly, not by assuming the sourcing agents' initial country-code guesses were correct.

A third issue surfaced after that: the inflation predictor initially used WDI CPI, which has large real gaps across this donor pool, including all of Liberia's pre-2002 history — forcing Liberia out of Hodler's own 9-donor pool. Switching to WDI's GDP-deflator inflation series resolved this for Liberia and for the wider candidate pool generally (full coverage for all 9 of Hodler's donors, and far better coverage than CPI across the full 43-country candidate list). This is the single biggest driver of the improvement in both the main result and the full-pool placebo rank.

## Why the earlier numbers moved, and in which direction

Separately, mid-project, a real numerical bug was found and fixed in how this project's code was using the `Synth` package's `genoud` optimizer (`kernlab::ipop`, the package's inner solver, could silently return a suboptimal result near sparse donor-weight solutions). Fixing it — verified against `Synth`'s actual documented algorithm (Abadie, Diamond & Hainmueller 2011, *JSS* 42(13)), not just patched ad hoc — moved the full-pool placebo result from an early p = 0.53, to p = 0.775 using a simplified GDP-only predictor set, to p = 0.667 using Hodler's real predictors but with CPI inflation (and Liberia excluded), to the current p = 0.474 using Hodler's real predictors with GDP-deflator inflation (and Liberia included). The direction of each fix has been to make the pipeline more faithful to the documented method and to the original donor pool, not to chase a more favorable number — and the numbers have moved in both directions along the way (weaker after the optimizer fix, stronger after each subsequent data-fidelity fix), which is itself evidence this is a genuine convergence toward the correct specification, not a search for a convenient one.

## One-line version

The path reconstructs almost exactly once Hodler's real predictor set and full donor pool are used; the statistical-significance claim improves substantially but still does not clear a conventional threshold at the correct, predictor-complete donor pool; both are reported, with the properly-sized full-pool test treated as the headline rather than a smaller, more flattering one.
